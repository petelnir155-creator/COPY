# nirpetel.com: האתר החדש

React + Vite + TypeScript + Tailwind + Framer Motion. RTL מלא, פריסה ב-Vercel.

## הרצה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בילד (בודק גם טיפוסים)
```

פריסה ב-Vercel: מחברים את הריפו, Vercel מזהה Vite לבד. בלי הגדרות.

## להוסיף קמפיין (דקה)

פותחים `src/data/projects.ts`, מעתיקים בלוק קיים ומשנים:

```ts
{
  id: "my-new-campaign",
  title: "שם הקמפיין",
  brand: "המותג",
  category: "creative", // או "social"
  videos: [yt("YOUTUBE_ID", "תווית"), yt("ANOTHER_ID", "גרסה ב'")],
}
```

- כמה סרטונים באותו קמפיין: מוסיפים עוד `yt(...)`. המודאל מציג כפתורי מעבר.
- Vimeo: `vimeo("ID", "תווית")`. טיקטוק/לינק חיצוני: `link("URL", "תווית")`.
- בלי סרטון: אפשר `parts: [...]` (רשימת פוסטים/מודעות) ו-`cover: "/covers/x.jpg"`.
- בלי `cover` הקאבר נלקח מהסרטון הראשון, ואם אין, נוצר קאבר טיפוגרפי.

## עמוד "קורות" (ציר זמן)

`#/cv`, מקושר מהנאב. האירועים ב-`src/data/timeline.ts`: להעתיק שורה `{ when, text }` ולשנות. השורה "תכף נמשיך..." בסוף
(`timelineTail`) נעלמת כשמוחקים אותה.

## משחקונים

`#/games`, מקושר מהנאב. כל משחקון הוא קומפוננטה ב-`src/components/games/` שמקבלת `{ onMore, onHire }`
(`onMore` חוזר לרשימה, `onHire` מעביר ל-`#contact`). להוספת משחקון: קובץ חדש + שורה אחת במערך `games` ב-`GamesPage.tsx`.
את הפופ-אפ הסוגר ("משחקון נוסף" / "אשמח להעסיק אותך") אפשר לעשות עם `GameOverModal`.

## דף הכיסוי ("הבוס מתקרב")

`#/news` (או המקש מעל Tab) מציג את "עולם הפרסום היומי": דף חדשות מזויף עם 3 כתבות. הכותרת והאייקון של הלשונית
מוחלפים לניטרליים, המוזיקה נעצרת, ובחזרה (המקש שוב, או "← ניר" בתחתית) הכל חוזר. הטקסטים ב-`src/components/NewsPage.tsx`.
הלשונית בנאב (עם השם הארוך בכוונה) מוגדרת ב-`site.ts` תחת `coverTabLabel`. בדסקטופ השם נגלל בתוך הלשונית, ובתפריט הצדדי במובייל הוא מופיע במלואו.

## עיצוב

צבעים ב-`tailwind.config.js`: `paper` (נייר), `ink` (דיו), `accent` (אדום-כתום, הצבע היחיד). טקסטים ב-`src/data/site.ts`.

## גרפיקת המשחקונים
הציורים (אצטדיון, שער, שחקנים, שולחן) נמצאים ב-`src/components/games/art/` כמחרוזות SVG. לשינוי צבעים או פרטים עורכים שם, והקומפוננטות (Football/Basketball/TableTennis) רק מזיזות אותם.
